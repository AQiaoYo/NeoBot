# 编写自然融入面板的插件设置

插件优先声明 Python 配置模型和业务设置分组，由宿主统一渲染。字段、下拉选择、业务按钮、通知预览、记录列表和开关共用宿主控件，权限、忙碌状态、输入保留和全局 InfoBar 也由宿主管理。只有标准控件无法表达的特殊交互才编写自定义页面。

## 创建插件工程

```powershell
uv run --no-sync python -m neobot_modloader.sdk init tmp/my_plugin --name my_plugin
uv run --no-sync python scripts/plugin_ci.py tmp/my_plugin --output-dir tmp/my_plugin_acceptance
```

内置模板包含配置模型、命令、思索和业务测试，不需要安装 Node。生成的 README 说明如何添加配置与业务入口。

## 普通字段：提供名称、说明和约束

```python
from pydantic import BaseModel, Field


class Config(BaseModel):
    """面板与插件共用配置约束，字段名保持存储兼容。"""

    interval: int = Field(
        default=60,
        ge=15,
        le=3600,
        title="检查间隔（秒）",
        description="每隔多久检查一次新内容。",
    )
    enabled: bool = Field(default=True, title="接收通知")
```

将模型传给 `Plugin(..., config=Config)`，面板自动提供字段、数值约束、恢复默认和保存入口。使用中文 `title`，不要把 `poll_interval_seconds` 之类的内部名称当成用户标签。字段名、默认值和保存语义不因改显示名称而改变。

| Python 声明 | 宿主控件 |
| --- | --- |
| `bool`、`int`、`float`、`str` | 开关、数字、文本输入 |
| `Literal`、`Enum` | 严格下拉，保留数字、布尔等原始值类型 |
| 嵌套 `BaseModel` | 带中文标题的配置分组 |
| `list[BaseModel]` | 可增删、复制和调整顺序的对象列表 |
| `list[str]`、`dict` | 标签/列表、键值编辑 |
| `SecretStr`、`SecretBytes` 或显式敏感字段 | 只写密码输入，不回读真实值 |
| 无法无损展开的联合、递归或特殊结构 | 保留原始类型的 JSON 编辑 |

配置章节复用真实字段描述，只用作者声明的样例值；不会把用户当前配置或业务记录当作思索数据。

## 业务设置：声明给宿主渲染

先声明真实动作及其输入、输出模型，再用 `plugin.settings()` 把需要用户操作的部分接入配置页。动作不会自动变成按钮；分组明确选择展示哪些动作。

下面是直播订阅插件的声明结构，引用的动作与资源在同一插件中注册：

```python
plugin.settings(
    "subscriptions",
    title="直播订阅",
    description="添加和调整订阅立即生效。",
    input_action="subscriptions.create",
    submit_label="开始监听",
    require_action="subscriptions.preview",
    fields=[
        {
            "name": "group_id",
            "control": "select",
            "options": {
                "action": "subscriptions.groups",
                "items": "items",
                "value": "group_id",
                "label": "name",
            },
        },
        {"name": "target", "placeholder": "粘贴直播间或 UP 主空间链接"},
    ],
    actions=[
        {"action": "subscriptions.resolve", "label": "识别", "display": "summary"},
        {"action": "subscriptions.preview", "label": "预览通知", "display": "html"},
    ],
    resource="subscriptions",
    edit_action="subscriptions.toggle",
    switch_fields=["push_live", "push_live_end"],
)
```

字段类型、标题和校验来自 `input_action` 的输入模型，`fields` 只补充界面提示。动态候选与辅助按钮只能引用 `read` 动作；主提交和行编辑必须引用写动作。行删除复用资源的 `delete_action`，提交参数按对应动作模型筛选，不把显示字段全部发回服务端。

分组默认直接展示；低频分组可显式写 `collapsed=True`。折叠由业务频率决定，不能由是否使用 iframe 决定。收起保留输入并暂停请求，打开思索时真实设置也保留并暂停。只读用户可以查看和执行获准的读取操作，写入仍经过原服务端权限和插件操作锁。

宿主根据设置区实际宽度组织内容：宽屏表单和预览并排，标签靠近控件，记录占满下方宽度；手机自动单列。预览在首次生成前显示空态，生成后可在同一工具栏查看原图和文字。没有必填输入的辅助状态读取放在记录标题附近。作者不需要为桌面和手机提供两份页面或复制布局 CSS；短文本可声明 `control="text"` 使用单行输入。

`require_action` 表示提交前需要当前输入对应的预览。任何输入变化都会使旧预览失效，重新预览失败也不能沿用旧确认。宿主阻止重复提交，并忽略过期读取。列表定时更新不覆盖输入；业务操作反馈只进入统一 InfoBar。HTML 结果放进无脚本、无表单权限的隔离预览，不注入宿主 DOM。预览默认适应窗口，可查看原始大小；输出可带 `width`、`height` 声明文档尺寸。

教程直接引用 `settings.<分组>.<字段或动作ID>`，列表引用 `settings.<分组>.resource`。思索复用同一个宿主设置组件，并且只读取 `guide.demo.actions` 和步骤 `example`，不执行真实动作。完整声明和业务实现见 `streaming_parser/panel.py` 与 `panel_guide.py`。

## 特殊交互：自定义页面

```python
plugin.view(
    "subscriptions",
    title="订阅管理",
    entry="web/subscriptions/index.html",
    anchors=["target"],
)
```

`index.html` 引用两个宿主资源，无需复制文件、安装前端框架或另写一套主题：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>订阅管理</title>
    <link rel="stylesheet" href="_ui.css">
    <script src="_sdk.js"></script>
    <script defer src="app.js"></script>
  </head>
  <body>
    <main class="nb-view nb-stack">
      <div id="target" class="nb-field">
        <label for="url">订阅地址</label>
        <div class="nb-inline">
          <input id="url" name="url" type="url" placeholder="https://…">
          <button class="nb-primary" type="button" id="add">添加订阅</button>
        </div>
        <p class="nb-help">填写要接收更新的页面地址。</p>
      </div>
    </main>
  </body>
</html>
```

按钮仍由 `app.js` 通过 `NeoBotPlugin.action()` 接入已声明业务。完整可运行示例见 `app/src/neobot_app/builtin_plugins/streaming_parser/web/subscriptions/`；权限、忙碌状态和思索演示使用同一份页面逻辑。

| 样式 | 用途 |
| --- | --- |
| `nb-view` | 内容根节点；设置区不额外套边框、背景或 padding |
| `nb-stack` / `nb-grid` | 纵向间距 / 双列字段；窄屏自动单列 |
| `nb-field` / `nb-help` | 字段名称、控件与补充说明 |
| `nb-inline` / `nb-actions` | 同行输入与按钮 / 可换行的操作组 |
| `nb-section` / `nb-section-heading` | 用间距和分隔线组织内容，不叠加卡片 |
| `nb-primary` / `nb-quiet` / `nb-danger` | 主操作 / 次操作 / 危险操作 |
| `nb-empty` / `nb-table-wrap` | 空列表说明 / 必要的表格横向滚动 |

公共样式覆盖输入、按钮、表格、焦点、禁用、手机触控尺寸和明暗主题。业务 CSS 只处理自己的内容结构；引用宿主 `--text`、`--panel`、`--brand` 等令牌，主按钮文字使用 `--text-on-brand`，不要写死白字。

## 内容高度与生命周期

首个设置分组默认展示，其余分组首次展开才加载。收起后保留页面和输入，并通过 `context.suspended` 暂停真实操作；再次展开使用原会话。打开思索也暂停真实设置，演示拥有单独会话和样例数据。

SDK 自动观察内容尺寸，使设置跟随外层正文滚动。页面根节点使用自然内容高度，避免 `100vh`、`height: 100%`、固定最小屏高或全页内滚动；局部图片预览、代码编辑器和宽表格可保留必要滚动。思索舞台使用独立尺寸，公共样式会自动补齐舞台内边距。

不要直接访问宿主 DOM。尺寸消息和业务请求均通过原有窗口、会话校验；页面仍处于 sandbox。共享 `_ui.css` 只在已声明页面的根路径提供，打包器允许引用它，但不会漏查 `assets/_ui.css` 等普通文件。

保存成功、失败和执行结果调用 `NeoBotPlugin.notify()`，统一显示在 InfoBar。字段错误可以原位标注 `aria-invalid`；长说明放入思索，不往表单里堆提示条。

## 验收

- 在桌面和手机查看首屏、长列表、空列表以及明暗主题。
- 确认增加内容后高度增长、删除后收缩，配置区只有一条正文滚动条。
- 收起再展开和打开再关闭思索后，原输入保持；暂停期间不执行真实动作。
- 校验只读、忙碌、版本冲突与敏感字段处理，操作结果只显示一次 InfoBar。
- 重新导出契约，执行插件工程检查和打包；宿主前端修改后重建分发资源。
